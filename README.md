## 🎮 Stop Ortográfico - Jogo Educacional

Um jogo interativo estilo **Stop/Adedonha + Gartic** desenvolvido para ensinar o uso correto de **ç, sc, ss** para alunos do 9°B.

## 🎯 Objetivo Educacional

Este jogo foi desenvolvido para ajudar os alunos a compreender e praticar as regras ortográficas em português, especificamente:

- ✍️ **Cedilha (ç)** - Usar antes de A, O, U
- ✍️ **SC** - Usar antes de E, I  
- ✍️ **SS** - Usar entre duas vogais (som de Z)

---

## 🕹️ Como Jogar

### Mecânica Principal
1. Uma letra é sorteada aleatoriamente (A-Z)
2. Você tem **60 segundos** para escrever o máximo de palavras que começam com essa letra
3. Escolha entre duas categorias:
   - **Palavra Normal:** Palavras sem ç, sc ou ss
   - **Com ç/sc/ss 🎯:** Palavras que contêm ç, sc ou ss (BÔNUS = 2 pontos!)

### Regras
- ✅ A palavra deve começar com a letra sorteada
- ✅ Não pode repetir palavras
- ❌ Palavras não reconhecidas serão marcadas como erro
- ⭐ Palavras especiais (ç/sc/ss) valem **DOBRO** (2 pontos)

### Pontuação
- Categoria Normal: **1 ponto** por palavra
- Categoria Especial: **2 pontos** por palavra ⭐

---

## 📚 Seção de Estudo

O jogo inclui uma seção educativa com:

### Ç (Cedilha)
**Quando usar:** Antes de A, O, U
- Paço (do palácio)
- Açúcar
- Cabeça
- Maçã, Louça, Carapuça

### SC (S + C)
**Quando usar:** Antes de E, I
- Ascendência
- Disciplina
- Fascinação
- Nascimento, Consciente, Adolescência

### SS (S + S)
**Quando usar:** Entre duas vogais (som de Z)
- Pássaro
- Classe
- Massa
- Necessário, Passagem
